# How I did set the app in the beggining
First thing I did was to set my node.js version to v22.23.2.
Then I installed Expo Go in my phone and created the initial enviroment using the following command in the terminal.
npx create-expo-app@latest habit-tracker-app --template blank-typescript
After that, a folder named "habit-tracker-app" was created and had the default template for expo's v57.
In the terminal, then I entered the new folder and used the following command
npx expo start
It appeared a QR code in the terminal, which I scanned using the Expo Go app on my phone.
